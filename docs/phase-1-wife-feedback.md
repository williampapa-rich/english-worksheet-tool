## 2. 평가 기준 (와이프 작성)

### 2.1 합격 등급 정의

각 등급에 본인 표현으로 정의를 채워주세요. 빈 칸 그대로 두거나, 제안 문구를 수정해도 됩니다.

| 등급  | 의미 (제안)                                                                         | 와이프 정의 |
| ----- | ----------------------------------------------------------------------------------- | ----------- |
| **A** | 수업에서 그대로 인쇄해서 학생에게 배포 가능                                         |             |
| **B** | 약간 수기 보완하면 사용 가능 (예: 라벨 위치 1~2개를 펜으로 옮김)                    |             |
| **C** | 한글에서 5~10분 이내 수동 편집 후 사용 가능                                         |             |
| **D** | 사용 불가. 기술 구현이 안되는 것으로 판단되고, 처음부터 재설계하거나 대안 모색 필요 |             |

**Phase 1 baseline 합격선** (이 등급 이상이면 Phase 1 OK 로 인정):

- [ ] A 만 합격
- [ V ] B 까지 합격
- [ ] C 까지 합격

### 2.3 검수 환경

- **한컴오피스 버전**: 한컴 오피스 한글 Mac용 (예: 한글 2022, 한컴오피스 2024 등)
- **검수 방식**:
  - [ ] 인쇄해서 검수
  - [ v ] 모니터 화면만 보고 검수
  - [ ] 둘 다
- **회당 검수 가능 시간**: 약 15 분
- **검수 빈도** (가능한 시간대): as many possible

### 2.4 NG 처리 우선순위 정책

검수에서 NG 가 여러 개 나왔을 때 어떻게 처리할까요?

- [ ] **모두 fix**: NG 한 개라도 있으면 P1-10 에서 모두 fix 후 재검수
- [ v ] **치명적만 fix**: 가중치 3 (치명적) NG 만 P1-10 fix, 나머지는 Phase 1 OK 처리
- [ ] **PM 재량**: PM(Dennis) 이 NG 목록 보고 판단
- [ v ] 다른 정책: 치명적인것 fix하는 건 기본으로 하되, 그 외에것들 PM에게 리스트 제공 후 추가 결정함

### 2.5 검수 진행 방식

- [ ] PM 동석 (같이 앉아서 코멘트 받아쓰기)
- [ ] 와이프 단독 검수 → 메시지 / 구글닥 / 본 문서에 직접 코멘트
- [ ] 처음 1라운드는 동석, 이후 단독
- [ v ] 다른 방식: PM 단독 검수. 최소기준은 PM 선에서 판단 가능함

## 1. 어휘 변형 — 본문 내장형 (A/B/C)

> variant_kind 후보: `vocabulary_inline_choice`

### 출제 의도

원지문 내 핵심 어휘 2~3곳을 의미가 유사하지만 미묘하게 다른 단어쌍/단어삼중 중 적절한 것을 고르게 함. **문맥 추론 + 어휘 변별력** 동시 측정. 단순 dictionary 의미 대조가 아니라 본문의 논리·tone과 정확히 부합하는 단어 고르기가 핵심.

### 표면 형태

- 원지문 본문 중간에 `(A) [embrace / reject]` 같은 박스 2~3개가 박힘.
- 문항 지문: "다음 글의 (A), (B), (C)의 각 네모 안에서 문맥에 맞는 낱말로 가장 적절한 것은?"
- 선택지 5개: `(A)col-(B)col-(C)col` 매트릭스 형태(예: `① embrace … rapid … include  ② embrace … slow … exclude  …`).
- 정답 1개.

### 원본 → 변형 규칙

**입력(스키마)**:
- `Passage`(원지문, 마커 분리된 정제 본문 — schema audit Gap K 권고 적용 가정).
- 메타: 학년/난이도, 출처.

**출력(스키마)**:
- `Question`(`variant_kind="vocabulary_inline_choice"`, `origin_question_id=null` 또는 원본 Question 참조).
- `Question.inline_choices: list[InlineChoice]` — 박스 N개(`label`, `options[2~3]`, `answer_index`, `position_marker`, `kind="vocabulary"`).
- `Question.choices: list[str]` — 5개 매트릭스 평탄화 또는 `choice_format="matrix_ABC"` + `choice_columns/rows`(audit Gap B / domain review §3.2 결정 의존).
- `Question.answer: int` — 1~5.
- `Question.explanation: str` — 각 박스별 정답 근거(본문 문맥 기반).

**자동 생성 가능성**:
- LLM 자동 1차 생성 + 사람 검수 필수. **단독 자동 생성으로 학생 배포 금지**(CLAUDE.md §1.3 가치 명제 3 + 본 분야 정답 유일성 위험).

### 검증 기준

- **정답 유일성**: 각 박스의 두/세 옵션이 본문 문맥 안에서 하나만 자연스러워야 함. qa-validator의 별도 LLM 호출로 "각 옵션이 모두 가능한지" 역방향 체크.
- **오답 매력도**: 오답 옵션이 너무 명백히 틀리면 변별력 없음. 동의어 또는 반의어 중 문맥 미세 차이로 오답이 되는 단어를 골라야 함.
- **어휘 수준 적합성**: 박스에 들어가는 단어가 대상 학년 수준 안. 너무 쉬운 단어(예: good vs bad) 또는 너무 어려운 단어(전문어휘) 회피.
- **본문 의도 보존**: 정답 단어로 채웠을 때 원지문의 주제·결론이 보존되어야 함.

### 흔한 실패 모드

- 두 옵션이 모두 문맥상 가능한 경우(정답 모호).
- 오답이 dictionary 동의어라 학생이 "둘 다 맞는데?"라고 느낌.
- 박스 위치가 문장의 핵심 의미를 결정하지 않는 비-핵심 단어(변별력 부족).

### 참조 자료

- exam-generator의 24개 유형 중 직접 대응 없음(Gap A — schema audit §3.1).
- 학교 내신 / 사설 변형문제집(아잉카, 마더텅 등)의 핵심 유형.
- 시각적 참고: 평가원 요약문(40)의 (A)/(B) 본문 박스 2개 패턴이 가장 가까운 평가원 표준.
- v0.1 작성 시점에 첨부 가능한 sample 미확보 — Phase 3 진입 전 와이프에게 sample 자료 요청(domain-review §5.4 참조).

## 2. 어법 변형 — 본문 내장형 (A/B/C)

> variant_kind 후보: `grammar_inline_choice`

### 출제 의도

원지문 내 어법 포인트(시제, 능동/수동, 관계사, 동명사 vs to부정사, 분사구문, 가정법 등) 2~3곳을 박스로 만들고 문법적으로 옳은 형태를 고르게 함. **문법 지식 + 문장 구조 분석**. 어휘형(§1)과 표면 형태는 동일하나 출제 의도가 명확히 구분된다.

### 표면 형태

- 어휘형(§1)과 동일한 (A)/(B)/(C) 본문 박스 + 5지선다 매트릭스 구조.
- 박스 안 옵션이 **단어 활용형의 변형** — 예: `(A) [is / are]`, `(B) [doing / done]`, `(C) [which / where]`.
- 문항 지문: "다음 글의 (A), (B), (C)의 각 네모 안에서 어법에 맞는 표현으로 가장 적절한 것은?"

### 원본 → 변형 규칙

**입력**: 어휘형(§1)과 동일.

**출력**: 어휘형(§1)과 동일하되 `InlineChoice.kind = "grammar"`.

**자동 생성 가능성**: LLM 자동 1차 + 사람 검수 필수. 어휘형보다 정답 유일성이 비교적 명확(문법 규칙은 결정적)하지만, **회색지대 문법 규칙**(예: 비제한적 관계사 that vs which, 가산/불가산 명사 경계 케이스)은 정답 모호 위험.

### 검증 기준

- **문법적 정답 유일성**: 두 옵션 중 하나만 문법적으로 옳아야 함. 둘 다 가능한 비제한적 케이스 회피.
- **어법 포인트 다양성**: 한 변형에서 (A)(B)(C) 박스가 모두 동일 포인트(예: 시제만 3개)면 학습 가치 떨어짐. **다른 어법 포인트 3개**가 권장.
- **본문 자연스러움**: 정답으로 채운 본문이 자연스럽게 읽혀야 함(문법은 옳지만 어색한 표현 회피).
- **표준 영어**: 미국식/영국식 차이로 정답이 갈리는 경우 회피(한국 영어 시험은 미국식 표준).

### 흔한 실패 모드

- 두 옵션이 모두 문법적으로 가능한 회색지대(예: 시제 일치의 예외).
- 박스 위치가 어법 포인트의 핵심이 아닌 부수적 요소(예: 관사 a/the 정도).
- 학년 수준 대비 너무 어려운 어법 포인트(고1에 가정법 도치 등).

### 참조 자료

- exam-generator의 어법(29) 유형이 가장 가까운 대응(평가원 어법은 본문에 ①~⑤ 마커 + 5개 밑줄 표현 중 하나 고르기 형태로, A/B/C 박스 3개 매트릭스와는 표면 형태가 다름).
- 학교 내신 어법 변형문제의 표준 형태.
- 1번 어휘 변형과 본문 마커·매트릭스 구조는 동일.

## 3. 빈칸추론 변형

> variant_kind 후보: `blank_inference`

### 출제 의도

원지문에서 핵심 단어/구/절 1곳을 `______`(빈칸)으로 비우고, 문맥상 가장 적절한 표현을 5개 선택지에서 고르게 함. **글의 전체 흐름·논리 추론**. 한국 영어 시험에서 변별력이 가장 큰 유형 중 하나.

### 표면 형태

- 본문 1곳에 `______`(언더스코어 6개 — exam-generator의 `BLANK_PLACEHOLDER`와 호환).
- 빈칸의 의미 단위에 따라 **3가지 sub-type**:
  - **빈칸-단어/구**: 명사구 1개 (exam-generator 빈칸-구(31)).
  - **빈칸-절**: 절 1개 (exam-generator 빈칸-절(32~34)).
  - **빈칸-문장**: 문장 1개(평가원에는 별 분류 없음, 사설 변형에서 등장).
- 선택지 5개: `["①", "②", "③", "④", "⑤"]` 평탄 list[str].
- 정답 1개.

### 원본 → 변형 규칙

**입력**: 원지문 `Passage`. 메타: 학년/난이도, 빈칸 sub-type 지정(또는 LLM이 본문 분석 후 결정).

**출력**:
- `Question`(`variant_kind="blank_inference"`, `type="빈칸-구(N)"` 또는 `"빈칸-절(N)"` 선택, exam-generator 24개 유형 분류와 호환).
- `Question.passage` — 빈칸이 박힌 본문(마커 분리 모델일 경우 `Passage.body_text` + 별도 `BlankAnnotation { position, span_in_original }`).
- `Question.choices: list[str]` — 5개 영어 표현(빈칸 sub-type에 맞춤).
- `Question.answer: int`.
- `Question.explanation: str` — 본문 흐름 + 정답 표현이 빈칸에 들어가는 논리.

**자동 생성 가능성**: LLM 자동 1차 + 사람 검수. 빈칸 위치 선택이 가장 어려운 부분(아무 곳이나 비우면 변별력 없음 — 본문 주제문 또는 thesis 문장의 핵심 부분이 표준).

### 검증 기준

- **정답 유일성**: 5개 선택지 중 정답만 본문 흐름·논리에 부합. 오답은 본문 표현을 변형해서 만들되 명백히 흐름과 어긋나야 함.
- **빈칸 위치의 변별력**: 빈칸이 본문의 **주제문/thesis 문장의 핵심 어구**에 위치해야 함. 부수적 위치(예: 예시 문장의 부사구) 회피.
- **오답 매력도**: 오답 5개 중 4개는 본문에 등장한 표현을 변형하거나 본문 일부와 의미적으로 관련되지만 빈칸 위치에 부적합한 형태. 무관한 표현은 변별력 없음.
- **본문 보존**: 빈칸을 정답으로 채우면 원지문과 의미·tone가 정확히 일치해야 함.

### 흔한 실패 모드

- 빈칸 위치가 본문 어디든 채워도 비슷한 비-핵심 자리.
- 정답이 본문 다른 곳에 그대로 등장(literal repetition — 빈칸 추론이 아니라 본문 검색이 됨).
- 오답 5개가 모두 무관해서 정답이 너무 명백.
- 빈칸이 너무 짧음(1단어)이라 추론이라기보다 어휘 문제가 됨.

### 참조 자료

- exam-generator 빈칸-구(31) — `BLANK_PLACEHOLDER = "______"` 6개 underscore 마커 사용. 선택지는 영어 명사구.
- exam-generator 빈칸-절(32~34) — 동일 마커, 선택지는 영어 절.
- 평가원 표준 + 사설 변형의 핵심 유형. 변형문제집에서 가장 자주 등장.

## 4. 어순 변형 (순서배열 신규 생성)

> variant_kind 후보: `order_shuffle`

### 출제 의도

원지문(보통 한 단락)을 의미 단위로 (A)/(B)/(C) 또는 (A)/(B)/(C)/(D) 단락으로 분할하고, 주어진 글 다음의 자연스러운 순서를 묻는다. **글의 논리적 흐름 + 응결성(cohesion) 단서(접속사, 대명사, 정관사 등) 추적**.

### 표면 형태

- "주어진 글" 박스(원지문 도입부 1~2문장).
- 그 아래 (A)/(B)/(C) 3개 단락(또는 (A)~(D) 4개).
- 선택지 5개: 가능한 순서 5개(예: `① (A)-(B)-(C)  ② (A)-(C)-(B)  …  ⑤ (C)-(B)-(A)`).
- 정답 1개.

### 원본 → 변형 규칙

**입력**: 원지문 `Passage`(단락 정보 보존 또는 LLM이 의미 분할).

**출력**:
- `Question`(`variant_kind="order_shuffle"`, `type="순서배열(36)"` 또는 `"순서배열(37)"` 호환).
- `Question.passage` — 주어진 글(첫 단락).
- `Question.sub_passages: list[list[str]]` — 3~4개 분할 단락(exam-generator 36, 37 구조와 호환).
- `Question.choices: list[str]` — 5개 순서 조합 문자열(예: `"(A)-(B)-(C)"`).
- `Question.answer: int`.
- `Question.explanation: str` — 순서 결정 단서(접속사, 대명사 reference, 정관사 등).

**자동 생성 가능성**: LLM 자동 1차 + 사람 검수. 단락 분할 위치 선택이 가장 어려움 — 의미 단위로 정확히 나눠야 단서가 작동.

### 검증 기준

- **정답 유일성**: 정답 순서가 응결성 단서로 일의적으로 결정되어야 함. 두 순서가 모두 자연스러우면 변별력 없음.
- **응결성 단서 충분**: 각 단락의 시작/끝에 다음 단락을 가리키는 단서(접속사 However/Therefore, 대명사 this/it, 정관사 the X 등)가 있어야 함.
- **단락 길이 균형**: (A)/(B)/(C)가 너무 길이 차이가 나면 학생이 단서 분석이 아니라 길이 추측으로 풀 위험.
- **본문 의미 보존**: 분할 후 정답 순서로 합치면 원지문 의미·결론이 정확히 복원되어야 함.

### 흔한 실패 모드

- 두 순서가 모두 자연스러움(단서 부족).
- 정답이 너무 명백(예: (A) 첫 문장에 강한 단서가 있음).
- 단락 분할이 의미 단위가 아니라 임의적(문장 중간에서 잘림).
- 5개 선택지에 정답이 아닌 명백히 불가능한 순서가 다수(변별력 없는 더미).

### 참조 자료

- exam-generator 순서배열(36, 37) — `sub_passages: list[list[str]]` 구조 그대로 활용 가능. 시스템이 (A)/(B)/(C) 라벨 후처리 부착.
- 평가원 표준 유형. 변형문제집에서도 변형 빈도 높음(원지문이 단락 1개여도 의미 단위로 쪼개서 변형 생성 가능).
- 변형 시 주의: 원지문이 1단락일 경우 LLM이 의미 분할을 해야 하며, 이 분할 자체가 LLM 출력의 핵심 품질 포인트.

## 5. 주제·요지 변형 (선택지 갱신)

> variant_kind 후보: `topic_main_idea_swap`

### 출제 의도

원지문의 주제(23) / 요지(22) / 제목(24) 중 하나를 묻되, 본문은 그대로 두고 **5개 선택지를 새로 생성**. 같은 지문으로 여러 번 재출제 가능 — 자산화 가치가 가장 높은 변형 유형.

### 표면 형태

- 본문 그대로(마커 없음 — exam-generator 요지(22)/주제(23)/제목(24)와 동일).
- 문항 지문: "다음 글의 주제로 가장 적절한 것은?" / "다음 글의 요지로 가장 적절한 것은?" / "다음 글의 제목으로 가장 적절한 것은?"
- 선택지 5개:
  - 주제(23) — 영어 명사구 5개.
  - 요지(22) — 한국어 단문 5개.
  - 제목(24) — 영어 제목구(대문자 첫 글자, 짧음) 5개.
- 정답 1개.

### 원본 → 변형 규칙

**입력**: 원지문 `Passage`. 메타: 변형 sub-type(주제 / 요지 / 제목 중 택1), 학년/난이도.

**출력**:
- `Question`(`variant_kind="topic_main_idea_swap"`, `type="주제(23)"` / `"요지(22)"` / `"제목(24)"` 중 sub-type에 맞춤).
- `Question.passage` — 원지문 그대로.
- `Question.choices: list[str]` — 5개(sub-type별 형식).
- `Question.answer: int`.
- `Question.explanation: str` — 본문의 thesis 문장 / 주제문 + 정답이 그것을 어떻게 압축하는지.

**자동 생성 가능성**: LLM 자동 1차 + 사람 검수. **본 5개 변형 중 LLM 자동 생성이 가장 안정적** — 본문 변형 없이 선택지만 갱신하므로 본문 훼손 위험 없음. 단 오답 매력도 확보가 까다로움.

### 검증 기준

- **정답 유일성**: 정답이 본문 thesis와 정확히 일치해야 함. 본문에 명시된 결론을 가장 정확히 압축한 것이 정답.
- **오답 매력도**: 오답 4개는 다음 패턴 활용:
  - 본문 일부 예시·세부사항만 강조한 too-narrow 오답.
  - 본문 주제를 너무 일반화한 too-broad 오답.
  - 본문에 등장한 표현을 변형하되 결론과 반대되는 오답.
  - 본문과 다른 주제의 그럴듯한 명사구.
- **sub-type별 형식 준수**:
  - 주제(23)는 영어 명사구(보통 정관사 the로 시작, 6~12 단어).
  - 요지(22)는 한국어 단문(15~30자).
  - 제목(24)는 영어 제목(대문자 첫 글자, 4~10 단어, 종종 콜론 구조).
- **본문 보존**: 본문은 변경 금지. 변형은 선택지만.

### 흔한 실패 모드

- 정답이 본문 첫 문장 또는 마지막 문장의 직역(literal) — 변별력 없음.
- 오답이 본문과 너무 무관해서 정답이 너무 명백.
- 오답 4개가 모두 too-narrow 패턴이라 단조로움(여러 패턴 섞기 권장).
- 영어 명사구의 문법적 형식 위반(예: 주제 선택지에 동사 시작).

### 참조 자료

- exam-generator 주제(23), 요지(22), 제목(24) 3개 유형이 직접 대응.
- 변형문제집에서 가장 자주 출제되는 유형 — 한 지문에서 주제 변형 1개 + 제목 변형 1개 + 요지 변형 1개를 모두 생성 가능.
- 본 카탈로그의 5개 변형 중 자산화 가치(같은 지문 여러 번 재변형)가 가장 큼.

## 6. 변형 유형 간 공통 검증 기준 (5개 모두 적용)

다음 항목은 5개 변형 유형 모두에 공통으로 적용되며, qa-validator agent가 별도 LLM 호출로 검증한다(Phase 3 DoD).

- **정답 유일성**: 5개 선택지 중 정답만 옳고 나머지 4개는 명확히 틀려야 함.
- **본문 의도 보존**: 변형 후에도 원지문의 주제·결론이 훼손되지 않아야 함(특히 §1, §2의 본문 내장형은 단어 swap이 본문 의미를 바꾸지 않아야 함).
- **학년 수준 적합성**: 어휘·구문이 대상 학년 범위 안.
- **저작권 인접**: 원지문 그대로 + 새 문항이라 학원 내부 사용은 회색지대 허용(CLAUDE.md §10.2). Phase 4 클라우드 배포 시 ADR.
- **사용자 검수 전제**: 모든 LLM 출력은 와이프(또는 강사)가 검수·수정 후 출력(CLAUDE.md §1.3 가치 명제 3).
